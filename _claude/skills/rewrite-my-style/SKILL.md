# rewrite-my-style

## Quick start

ユーザーが書き換えたいテキストを貼り付けたら、[STYLE-GUIDE.md](STYLE-GUIDE.md) のルールに従って書き換えて返す。

```
[書き換えたいテキストをここに貼る]
```

## Workflow

1. テキストを受け取る
2. 記事の性質を判断する（論考系 or 個人的な振り返り系）
3. STYLE-GUIDE.md のルールを適用して書き換える
4. 書き換え後のテキストをそのまま返す（説明は最小限に）

## 記事タイプの判断

| タイプ | 基本文体 | 例 |
|--------|----------|-----|
| 論考・専門的（EMの話、フレームワーク解説） | だ・である調 | 「〜が重要だ」「〜となる」 |
| 振り返り・抱負・イベントレポート・個人的な話 | です・ます調 | 「〜でした」「〜と思います」 |

両タイプとも、口語的な語尾（「〜なぁ」「〜よね」「〜かな」）や感嘆符（！）は自然に混じってよい。

## 核心ルール（優先度順）

1. **AIらしい整いすぎた文章を壊す** — 完璧な並列・対称構造を崩し、ひとの思考の流れに近づける
2. **一人称の語りにする** — 「〜と考えられる」→「〜と思う」、受け身・客観調を一人称に変換
3. **感情・反省を隠さない** — 「できていない」「大変だった（笑）」「嬉しかった」などを残す or 追加
4. **具体的な自分の経験に落とす** — 抽象論だけで終わらせない
5. **語尾を柔らかくする** — 断定を和らげる（「〜だ」→「〜だと思う」「〜なぁ」）

詳細ルールは [STYLE-GUIDE.md](STYLE-GUIDE.md) を参照。

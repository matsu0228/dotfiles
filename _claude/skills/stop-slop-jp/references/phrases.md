## 1. 定型句と偏愛語

### 表層の定型句

- 「いかがでしたでしょうか」「いかがでしたか」
- 「ぜひ参考にしてください」「ぜひ〜してみてください」
- 「○○の重要性を再認識しました」
- 「近年〜が注目されています」
- 「現代社会において〜は重要なテーマです」
- 「○○することが大切です」「○○することが重要です」
- 「○○に他なりません」
- 「ご質問ありがとうございます」

### AI偏愛語

チューニング済みのモデルでも残る、いまの臭いの中心。

**質感を装う語：** 泥臭い、手触り、肌感・肌感覚、体温・温度感、熱量、血の通った

**認知を装う語：** 解像度（「解像度が上がる」）、腹落ち、メンタルモデル、文脈（やたら言いたがる）

**評価を装う語：** 本質・本質的、地に足のついた、等身大

**抽象比喩：** 営み（「○○という営み」）、装置（「○○装置」）、設計（体験に対して「設計されている」）、インフラ（抽象用法）、接続（「人の接続」のような抽象用法）

**思想語：** 思想（「○○の思想」）、原則（「3つの原則」）、哲学（「○○の哲学」）

### 必殺技造語（壮大化のための漢字熟語）

普通の感想を大きな話に仕立てる語。複数並ぶと一発でAI臭になる。

真理・真実、結末・宿命・運命、境地・極致・究極、虚飾・装飾・虚像、美学・徳・品性、重厚感・深淵、禁欲的・優美・優雅・繊細、残酷・冷徹・冷酷・過酷、凝縮・結晶・結実

> 「枯淡の境地」「冷徹な結末」「残酷な真理」のような組み合わせは一発でAI臭。普通の感想は普通の語彙で書く。

### 比喩のテンプレ語

同じ記事で3回以上使ったらAI臭。

- 地図・羅針盤・コンパス
- 仕様書・設計書・レシピ
- 土台・柱・骨格
- 栄養・エンジン・潤滑油・スパイス
- DNA・車の両輪
- 触媒・起爆剤

## 2. 翻訳調

### 翻訳調動詞

主体を抽象化した分析動詞。英語の point to / suggest / emerge などの直訳。「誰が」を立て直す。

- 指している（「同じ方向を指している」）
- 示している・示唆している
- 物語っている
- 浮かび上がる・見えてくる
- 対比をなしている
- 収斂する
- 整理する・考察する
- 捉える・論じる・位置づける

### アカデミック自称

ブログ本文で使うと翻訳論文っぽくなる。

- 「本稿」「本記事」「本論考」「筆者」（地の文で）

## 3. 英語ネイティブ思考の漏れ

### 横文字メタファー（IT用語の比喩使用）

| 避ける | 使う |
|---|---|
| 思考のOSをアップデートする | 考え方を変える |
| 人生をハックする | 工夫する、コツを掴む |
| 新しい習慣をインストールする | 習慣をつける |
| マインドをリファクタリングする | 考え方を整理する |
| 頭の中にラボを持つ | 頭の中で試す |
| キャリアをポートフォリオで考える | 仕事の組み合わせで考える |
| 学びをアセットにする | 学びを積み上げる |

### 過剰なカタカナ表記

普通の日本語に戻せるのにカタカナのままにするクセ。

| 避ける | 使う |
|---|---|
| コンテキスト | 文脈・状況 |
| アライメント | 揃える・合わせる |
| コミュニケーション | 話す・伝える |
| インテグリティ | 誠実さ・一貫性 |
| コラボレーション | 共同作業・連携 |
| インプリメンテーション | 実装 |
| プライオリティ | 優先 |
| アグリー | 同意・賛成 |
| ナレッジ | 知識・ノウハウ |

技術用語は技術用語のまま使ってよい。

### 英語固有名詞の律儀さ

正式名称をフルで毎回書くクセ。フル正式名称が3つ以上並んだら警戒。「ChatGPTは」「Claudeは」のようにレイヤーを揃えずに混ぜても自然。

## 4. 立場を薄める語

### 結論回避フレーズ

全立場を紹介してどれも選ばないAIのデフォルト挙動。

- 「ケースバイケース」「場合によります」「価値観によります」「状況に応じて異なります」
- 「一概には言えませんが」「一般的には」
- 「メリットもあればデメリットもあります」
- 「○○という側面もありますが、一方で〜」「賛否が分かれるテーマです」

### 三段ヘッジ

同じ段落で複数のヘッジを重ねるとAI臭。1段落に1つまで。

- 「○○ことがある」「○○場合がある」「○○可能性がある」「○○なりうる」
- 「○○とは限らない」「○○と言えなくもない」「あくまで○○として捉えるのが正確だ」

### 曖昧な断言

「重要だ」と言うが、具体的に何が・どう・なぜ、を書かない。

- 「本質的な問題がある」「構造的な課題である」「示唆に富む結果だ」
- 「重大な意味を持つ」「根本的な転換が必要だ」「深い洞察が得られる」

→ 修正：具体的な「何が」「なぜ」を書く。書けないなら削る。

### 弱い否定

「やるな」と言うべき場面で弱めるクセ。「やるな」「ダメだ」と言い切る。

- 「あまり推奨されません」「注意が必要です」「望ましくないとされています」「避けたほうが良いでしょう」

### 根拠なしの強い評価

- 「非常に有効です」「画期的な手法です」「革新的なアプローチです」「大きなメリットがあります」

## 5. 時間稼ぎと自己解説

### 咳払いの前置き

本題に入る前の時間稼ぎ。削除して直接本題に入る。

- 「実はですね、」「結論から言うと」（言いつつ結論が薄い場合）
- 「正直に言うと」「率直に言いますが」「ここで重要なのは」
- 「ひとつ言っておきたいのは」「結局のところ」「あえて言うなら」

### メタコメント

構造を本文で予告するパターン。

- 「以下の3つの観点から説明します」「それぞれ順に見ていきましょう」
- 「ここからが本題です」「補足ですが、」「ステップ1」「STEP1」
- 「○○について、改めて整理します」

## 6. 強度の振り切り

### 根拠なし副詞

1段落に2個以上重なったらNG。

- 非常に、とても、かなり、めっちゃ、ガチで、マジで
- 普通に（意味のない強調用法）、本当に、実に、確かに（意味のない同意）

### 「○○すぎる」連発

1記事に2〜3回まで。全部に貼らない。中間温度（「悪くない」「まあまあ」「微妙」）を混ぜる。

### 「(笑)」の文末貼り付け

絵文字的に律儀に付けるクセ。1記事に1〜2回まで。

## 8. 機械的なアーティファクト

出力処理の痕跡。検索→全置換で機械的に潰せる。

- **`**` 残骸** — Markdown強調記号の消し忘れ
- **コロン後の半角スペース** — `重要な要素： テクノロジーと` のような半角混入
- **全角文字に紛れた半角スペース** — `対策をする ためには` のような不要スペース
- **全角ダッシュ `──`** — 英語 em-dash の直輸入。日本語ではコロン・改行・読点に置き換える

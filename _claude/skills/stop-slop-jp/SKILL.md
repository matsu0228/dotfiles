# stop-slop-jp — AIくさ抜き

## Quick start

書き換えたいテキストを貼ると、AIっぽい表現を除去して返す。

## Workflow

1. 語彙・フレーズレベルの問題は [references/phrases.md](references/phrases.md) を参照する
2. 構造レベルの問題は [references/patterns.md](references/patterns.md) を参照する
3. 書き換え後のテキストをそのまま返す（説明は最小限に）

# 何を変えないか

- 固有名詞・数値・事実関係は絶対に変更しない
- 文書の骨格（伝えたい内容の順序）は基本的に維持する
- 箇条書き自体は悪ではない — 「箇条書きしか使っていない」状態を直す
